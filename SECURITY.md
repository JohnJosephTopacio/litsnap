# Security Policy

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Report privately via GitHub: **Security → Report a vulnerability** on this repository. Include steps to reproduce and the impact you expect. You'll get a response as soon as possible.

## Scope

LitSnap stores books only in the user's browser. The lookup Worker receives only the normalised lookup term. Reports about leaking book content, bypassing rate limits, or exposing secrets are especially welcome.
